# v7.5 新手首周操作手册

> 欢迎使用量化交易系统 v7.5。本手册带你从零开始，10天完成从观察到实盘的成长。

---

## 第1天：安装与准备

### 今日任务
1. **安装 Bark 手机应用**（App Store 搜索"Bark"）
2. **接收第一条推送**：系统会在每个交易日15:30后自动发送
3. **阅读心理指南**：打开 `psychology/newbie_guide.md`，花30分钟读完

### 重要提示
- 🔵 你现在处于**观察期**（第1-5天）。**请勿实盘！**
- 推送中看到的买入指令仅供学习参考
- 今天的任务只是：理解系统在做什么

### 如何读推送
推送看起来像这样：
```
🔵05月14日 买入17只
🔵 观察期 - 请勿实盘

1. 宏盛华源 800股 止损5.51
2. 山东赫达 100股 止损23.05
...
共17只 | 按指令卡操作
详情见 orders/daily_instruction_20260514.md
```

每条指令包含：
- **股票名称**：买什么
- **股数**：买多少
- **止损价**：跌破就卖的铁律价格

## 第2-5天：观察期

### 每日任务
1. **收到推送后**，在纸上或Excel记录今日推荐的股票
2. **第二天开盘后**，观察这些股票的实际走势
3. **收盘后对比**：推送推荐价 vs 实际收盘价

### 学习目标
- 理解"止损"的重要性：它不是亏损，是保护
- 观察"趋势跟踪"的特点：不是每只都涨，但涨的幅度大于跌的
- 建立对系统的信任（或怀疑——有疑问是好的）

### 常见问题

**Q: 为什么今天推荐的股票，第二天跌了？**
A: 趋势跟踪策略天然低胜率（约50-55%）。关键不是每次都赢，而是赢的时候赚得比亏的时候多。10只股票中5-6只可能亏损，但亏损被止损控制在-8%以内，而盈利的可能涨15-20%。

**Q: 推送没收到怎么办？**
A: 检查Bark是否联网、Token是否正确。Bark依赖Apple推送服务，偶尔延迟正常。也可以查看 `orders/bark_simple_YYYYMMDD.txt` 文件。

**Q: 我想改止损价，可以吗？**
A: **不要改。** 止损价是系统基于ATR（平均真实波幅）计算出来的。放宽止损 = 单笔亏损更大；收紧止损 = 容易被随机波动震出。系统比你更懂什么时候止损。

**Q: 亏了怎么办？**
A: 打开当天的心理日记（`psychology/daily_YYYYMMDD.md`），读一遍。如果还是焦虑，关掉交易软件，去做别的事。明天又是新的一天。

## 第6-10天：模拟期

### 每日任务
1. **接收推送后**，在模拟盘或Excel中"建仓"
2. **每天记录**：如果跟单，盈亏是多少
3. **第10天统计**：累计盈亏、胜率、最大回撤

### 模拟方法
- **方法A（推荐）**：用同花顺/东方财富的模拟盘功能，按推送指令操作
- **方法B**：在Excel中记录每笔"虚拟交易"的入场价、出场价、盈亏

### Excel模板
```
日期 | 股票 | 买入价 | 卖出价 | 盈亏 | 出场原因
05/15 | XX股份 | 10.50 | 10.80 | +2.86% | 到期
05/17 | YY科技 | 15.20 | 14.10 | -7.24% | 止损
...
```

### 学习目标
- 体验"大部分交易小亏、少数交易大赚"的统计特征
- 建立操作纪律：每天固定时间操作，不盘中追涨杀跌
- 完成10天模拟后，用数据（而非情绪）决定是否实盘

### 记录你的交易（重要！）
系统需要你的真实/模拟交易数据来优化策略。请养成每日记录的习惯：

**方法1：命令行快速录入**
```
python log_real_trade.py
```
按提示输入：日期、代码、买卖方向、价格、数量即可。手续费自动计算。

**方法2：直接编辑Excel**
打开 `real_trades.csv`，按表头格式填入每笔交易。记得删除示例数据行。

**方法3：周末集中补录**
每周日系统会自动推送健康报告，Bark中会提醒检查 real_trades.csv 是否完整。
周末心理学习任务中也包含"核对真实交易记录"环节。

> 提示：模拟期的交易也值得记录（在备注中标明"模拟"），这样系统可以对比你的模拟执行与理想执行之间的差距。

### 如何记录交易原因（v7.5新增）

每笔交易录入时，在"备注"栏填一个简短的原因。系统会分析你的备注，给出个性化的行为建议。

**常见备注示例：**
- "跟单系统" — 完全按系统指令操作
- "看见爆拉怕回调" — 因为恐惧提前止盈
- "跌了害怕赶紧卖" — 因为恐惧止损
- "急需用钱" — 非交易原因的操作
- "手滑" — 操作失误

**为什么值得花10秒填备注？**
- 系统会检测你的情绪模式（如多次"害怕"备注 → 推送心理学课程）
- 跟单盈利时会得到正面强化
- 周末可以回顾，发现自己的行为盲点

**完全不强制**：不填备注，系统一切功能正常运行。

### 如何检查自己是否准备好升级（v7.5新增）

打开仪表盘 → "学习中心" → 展开"阶段状态 & 升级准备度"面板：

| 指标 | 如何达标 |
|------|----------|
| 学习主动度 | 打开"学习中心"页面（自动记录）+ 阅读心理日记 |
| 交易录入度 | 在real_trades.csv中录入交易（模拟期≥2笔，预备期≥5笔） |
| 纪律表现 | 遵守止损、不追高、不频繁交易 |
| 自评意愿 | 点击"我觉得我准备好了"按钮 |

- 满足至少2项（总分≥50分）→ 系统建议升级
- 点击"确认进入下一阶段"完成升级（主动升级）
- 连续3天不回应 → 系统自动推进（被动升级）
- 第15天仍无积极信号 → 保底自动推进

## 第11天起：实盘预备期

### 判断标准
系统会根据近5日模拟表现自动判断：
- ✅ **模拟累计收益为正** → 推送显示"模拟验证通过，可考虑实盘"
- ⚠️ **模拟累计收益为负** → 推送显示"模拟亏损，建议延长观察"

### 如果决定实盘
1. **初始仓位不超过总资金的20%**：比如你有10万，先拿2万试
2. **前三笔交易不要超过5000元/笔**：用最小的金额积累实战经验
3. **严格按止损执行**：实盘的心理压力远大于模拟，止损纪律是第一生命线
4. **不要"补仓"**：亏损的股票不是"更便宜了"，是趋势坏了
5. **继续做模拟**：实盘和模拟并行，用模拟验证"如果全跟单"的效果

### 如果继续观察
- 没有关系。宁可多观察10天，也不要在没准备好的时候入市
- 继续记录模拟数据，积累到20-30笔交易后再评估
- 参加学习中心的周末任务，提升交易认知
