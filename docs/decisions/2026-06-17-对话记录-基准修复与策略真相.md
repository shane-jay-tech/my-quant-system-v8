## 二、数据刷新后,ETF 闸门露出 -10% 信号 → 用户问"策略是不是一直在亏钱"

### 排查真相(关键)
1. 回测报"超额 -10%/净 -9%",但**毛收益其实是正的**(+0.1%~+1.3%)——亏损几乎全来自"成本"。
2. 那个"成本 10%、1298 笔一模一样"= 回测假设**每笔只交易 100 元**,被 5 元佣金底价吃掉 10%。但实盘仓位逻辑(小资金锁全仓买最强3只)实际每笔几百到上千元。
3. 真实选股追踪(不含成本):平均次日 -0.47%、胜率 42%、近期转正 —— 普通,**不是"一直在亏"的灾难**。

### 用户诉求:"要最能赚钱的方案,按我能赚钱方向改"

### 两次修复尝试 —— 都被多模型对抗审拦下,已全部撤回
- **尝试一**(把回测成本改成"按集中3只≈800元/笔"算):DeepSeek 判 **CRITICAL**——回测仍记每天~10笔交易,却只按3笔的集中金额算成本(等于在2400元上摊8000元),**低估成本=自我美化**。撤回。
- **尝试二**(commission_min 全局 5→0,即"按无底价"):一度因 `real_trades.csv` 手续费仅 0.17~0.82 元、误判用户无底价。但落地时发现"5元底价"假设**深植 6+ 模块**(cost_model / log_real_trade / sim_trade / replay / app / bark 硬编码 FLOOR),属系统级大改,且基于未确认推断 → 守住"不鲁莽改钱"的线,撤回,183 测试回绿。

### 防偏置原则(本次严格执行)
Claude 既是系统作者又是裁判,改动天然会美化自己。所以两次"让数字变好看"的改动都先立验收标准、交 DeepSeek/Kimi 对抗核验,被判有问题即撤回,绝不单方面通过。

## 三、用户确认:"我有最低5元的佣金"

- ⚠️ 矛盾点:用户记录 `real_trades.csv` 手续费记为 0.17~0.82 元(像是无底价),与"有5元底价"冲突。判定为**当初录入填错**,以用户口述为准 = **有5元底价**。建议用户以后按真实账单填手续费。
- **真相落定**(在两个极端之间):

  - +1.16% 也是错的(误以为无底价时算的);
  - **真实**:用户每笔几百到上千元,5元底价摊上去 ≈ **每笔来回 1.5%~2.5%**;策略毛收益10天才 +1% 出头 → **扣掉摩擦基本打平、甚至小亏**。

## 四、最终结论(诚实,未迎合"最赚钱"压力)

1. **用户没在亏大钱,但策略也没有可证明的赚钱本事(edge)**——胜率近似掷硬币,只跟踪指数。
2. **没有任何代码能改出利润**。硬调参数让回测好看 = 曲线拟合(Goodhart),上实盘只会亏更多,拒绝做。
3. **5元底价是关键**:每交易一次先被啃 ~2% 过路费,去换一个没 edge 的信号 → 交易越勤亏越多。
4. **最赚钱的方案 = 少交易、买沪深300ETF(510300)长持**:
   - 买了拿住,5元底价基本只交一次(≈0.2%),安心吃大盘 beta;
   - 继续天天选股,每轮换仓交一次~2%过路费,长期必输给"买了拿住"。
   - 想留三五百块跑策略找手感可以,主力别 churn。
5. 想更高收益只能靠重押冒险(赌),期望收益并不更高,不能诚实叫"最赚钱"。
