# 仪表盘人体工学与视觉升级

> 日期：2026-08-24 · 系统版本：v8.6 · 难度评分：3/12（L2 常规）
> 协作：GPT-5.6 Luna 只读 UX 审查 → 主实现与浏览器验收 → DeepSeek 独立 diff 复审（无阻断）

## 固化目标（严格 200 字）

在不修改选股、交易、回测和风控逻辑的前提下，完成人体工学与视觉升级：采用深蓝灰交易终端风格，保留 A 股红涨绿跌；重组侧栏导航、稳定页面标识；统一字体、间距、卡片、按钮、表格与状态反馈；让选股、模拟交易和系统健康页优先呈现结论、动作与风险，折叠次要信息；优化桌面端并保证窄屏可用；补充导航与渲染测试，用浏览器检查对比度和溢出；不触发真实流水线或推送，保留现有改动，归档证据并追加 memory.md。

## 审查结论

- 原导航是 8 项未分组单选框，点击目标弱，显示文案直接承担路由值。
- 选股日期在常见桌面宽度被截断，首选渐变卡正文对比度不足。
- 模拟交易先展示大量订单与回放，账户权益、现金、盈亏、胜率出现过晚。
- 健康页先展示 37 项能力清单，真正的健康结论被推到首屏以下。
- 全流程按钮单击即联网运行并发送 Bark，存在误操作风险。
- 没有窄屏规则，四列布局和按钮组在小窗口中容易挤压。

## 落地改动

- `app/styles.py`：建立 CSS 变量与浅色内容区、深蓝灰侧栏、低饱和卡片、44px 控件、焦点环、减少动效和 900/600px 响应式规则。
- `app/sidebar.py`：导航改为“每日决策 / 分析复盘 / 系统管理”三组按钮，使用稳定页面 ID 和 session state；保留新手模式与本地重载行为。
- `app.py`：路由改为稳定 ID → 渲染函数映射；窄屏由 Streamlit 自动收起侧栏。
- `app/pages.py`：选股卡对动态文本做 HTML 转义，修复日期截断和理由低对比度；统一 A 股红涨绿跌；模拟账户概览置顶；本金设置和严格回放折叠；健康能力清单后移折叠；全流程增加明确确认门槛。
- `tests/test_dashboard_apptest.py`：覆盖 8 个页面、稳定导航和全流程默认禁用，共 11 项仪表盘测试，避免点击真实业务按钮。

3. 本轮没有重做 Plotly 图表主题，图表仍沿用原有配色；不影响可读与功能，可在后续独立视觉迭代中统一。
